# Exonara

Native Python differential exon usage from prepared exon counts.

**Research alpha · 0.1.0a1 · Python 3.11+**

Exonara implements the two-condition exon-versus-other-exons negative-binomial
likelihood-ratio analysis used by DEXSeq. Each exon is compared with the summed
counts of the remaining exons in its gene, with a separate effect for every
sample. This distinguishes differential exon usage from changes in total gene
expression.

The supported end-to-end path estimates median-ratio size factors, exon
dispersions using a Cox–Reid correction, a **mean dispersion trend** and
log-dispersion shrinkage, then tests the condition-by-exon interaction and applies
Benjamini–Hochberg adjustment. Normal use requires no R runtime.

## Quickstart

From a source checkout:

```sh
python -m pip install -e '.[dev]'
python examples/quickstart.py
python -m pytest
```

For your own prepared tables:

```python
import pandas as pd
from exonara import test_deu

# Rows are uniquely identified counting bins; columns are biological samples.
counts = pd.read_csv("exon_counts.csv", index_col="feature_id")
gene_ids = pd.read_csv("gene_map.csv", index_col="feature_id")["gene_id"]
condition = pd.read_csv("samples.csv", index_col="sample_id")["condition"]
# condition contains numeric 0 (reference) and 1 (comparison).
result = test_deu(counts, gene_ids, condition)
result.table.to_csv("exon_usage_results.csv")
print(result.diagnostics)
```

Supply raw, nonnegative integer counts and a complete exon-to-gene map. Sample
and exon metadata are aligned by identifiers. Automatic dispersion estimation
requires at least six biological samples total, with at least two in each
condition. Smaller replicated designs require an explicitly supplied prior
variance or scientifically justified dispersions. See the
[support matrix](docs/support-matrix.md) before interpreting results.
Supplied dispersions must be finite and between `1e-8` and
`max(10, 2 * number_of_samples)`, inclusive.

`result.table` includes raw, trend, and final dispersion, LRT statistic, p-value,
adjusted p-value, and a per-exon status. `log2_usage_odds_ratio` measures the change
in this-exon/other-exon odds; it is **not DEXSeq's separate
`estimateExonFoldChanges` output**. Unsupported or failed fits have missing test
results and an explicit status.

## Evidence and limits

Committed fixtures were generated by **R 4.6.1, DEXSeq 1.58.0, and DESeq2 1.52.0**
on synthetic data: 72 tested exons, two deliberately non-testable bins, six
samples, and two conditions. Fixed-dispersion and complete estimated-dispersion
analyses are compared independently. See
[the machine-readable report](reference/comparison-report.json) and
[validation documentation](docs/validation.md).

This is a limited implementation of DEXSeq's statistical workflow, not a complete
replacement for DEXSeq. The initial release supports the upstream
`fitType="mean"` option; it does not reproduce the default parametric/local trend,
arbitrary design formulas, read counting, annotation flattening, independent
filtering, or Cook's-distance filtering. Sparse boundary cases are explicitly
excluded. Agreement on these fixtures does not establish general scientific
equivalence or clinical suitability.
