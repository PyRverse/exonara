# Provenance and attribution

Exonara 0.1.0a1 contains an original Python implementation informed by inspection
of the upstream DEXSeq and DESeq2 implementations. This is **not a clean-room
claim**. The normalization, dispersion initialization, Armijo search, two-stage
grid fallback, mean trend, MAP shrinkage, and dispersion-outlier rules were
adapted from upstream algorithms. The paired full/reduced model follows DEXSeq.

Official release sources reviewed:

- DEXSeq 1.58.0, revision `847ca9b8fec10d109175501051311f6cca1453d7`,
  GPL (≥3): `R/core.R`, `R/methods.R`, `R/classes.R`, and `DESCRIPTION`.
- DESeq2 1.52.0, revision `16aeab6d6158bd8cbb8e98764c2f33399b1a3fd3`,
  LGPL (≥3): `R/core.R`, `R/methods.R`, `R/fitNbinomGLMs.R`, `R/wrappers.R`,
  `src/DESeq2.cpp`, and `DESCRIPTION`.

[source-audit.json](reference/source-audit.json) links each exact source revision
and records its content hash. Development versions DEXSeq 1.59.0 and DESeq2 1.53.6
were initially consulted; validation and release-source audit use the versions
above. The original upstream source caches are ignored and are not shipped as
package code.

The official [DEXSeq vignette](https://bioconductor.org/packages/release/bioc/vignettes/DEXSeq/inst/doc/DEXSeq.html)
defines the this-exon/other-exons construction and nested model test. Original
method citations are included in the README. Please credit those authors when
using or extending this implementation.

No upstream trademarks, images, or restricted datasets are bundled.

Reference outputs were generated by actual R execution using the committed
synthetic-data generator. R/package/platform metadata, generator seed, and file
hashes are retained. The comparison report records measured results and limited
scope. Validation is automated, but this alpha has not received an independent
statistical-maintainer review or an upstream endorsement.
